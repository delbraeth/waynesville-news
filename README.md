# Waynesville Daily Brief — `waynesville.news`

Hyperlocal daily news for **Waynesville, OH, Corwin & Warren County**. Static site built with
[Astro](https://astro.build), deployed free on **Cloudflare Pages**. Domain & email at Spaceship.

See `PROJECT_PLAN.md` and `SOURCES.md` for the full plan and source catalog.

> **Status: Phase 1 demo build.** The layout and structure are real and production-ready.
> Most words are placeholders and are clearly labeled — a DEMO banner sits at the top of every page.
> The **events are real** (venues/sources), though some dates are marked "confirm."
> No real names, quotes, or specific claims are invented anywhere.

## Run it locally

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs the static site to dist/
npm run preview  # preview the built site
```

Requires Node 18+ (built and tested on Node 22).

## Project structure

- `src/pages/` — routes: home, `/events/`, `/schools/`, `/government/`, `/around-town/`, `/public-safety/`, `/about/`, `/briefs/`
- `src/content/briefs/` — daily briefs as Markdown (**the content model** — one file per day)
- `src/components/` — masthead, info bar (weather + next meeting), the events engine, headline lists, section blocks, footer
- `src/data/` — `weather.json`, `next-meeting.json`, `events.json`, `headlines.json` (regenerated by the pipeline)
- `src/styles/global.css` — the whole design system (one file)

## How publishing works (the editor-in-the-loop gate)

Add a file `src/content/briefs/YYYY-MM-DD-slug.md`:

```markdown
---
title: "Tuesday Brief: ..."
date: 2026-08-18
dek: "One-line summary."
demo: false
---

Markdown body with the day's sections...
```

Commit it → Cloudflare Pages rebuilds and deploys automatically. **That commit is the publish step.**
Set `demo: false` on real editions (removes the sample-edition callout).

## The pipeline (Phases 2–3 — not built yet)

Each weekday a scheduled task will: pull sources (weather via the NWS API, Wayne Local, county/village
government, event venues), draft a brief into `src/content/briefs/` and refresh `src/data/*.json`, then
stage it for your review. On approval it commits → auto-deploys. Details in `PROJECT_PLAN.md`.
